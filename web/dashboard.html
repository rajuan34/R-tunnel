R-Tunnel Android Termux Quickstart

            

            
            

              R-Tunnel establishes an authenticated, persistent outbound WebSocket bridge between your Android device running Termux and your Render cloud server.
              Local HTTP servers (Node, Python, Go, PHP) are instantly published with public HTTPS URLs without port-forwarding or public IP addresses.
            


            
Step 1: Install Node.js in Termux

            
pkg update && pkg install nodejs


            
Step 2: Install R-Tunnel Client CLI

            
npm install -g r-tunnel


            
Step 3: Connect & Expose Local Port

            
rtunnel 8080


            

              
Security & Operational Architecture

              

                • Strict Localhost Shielding: Outbound client connections strictly dispatch to 127.0.0.1 to prevent SSRF lateral traversal.

                • Server-Authoritative Expiration: Duration countdowns and expirations are enforced centrally on Render.

                • Binary Safe Transport: Media streams, images, and binary archives are seamlessly encoded as Base64 across WebSockets.

                • Timing-Safe Authentication: Password and token comparisons use constant-time operations to resist side-channel timing analysis.
