R-Tunnel Android Termux Quickstart

R-Tunnel is a production-grade, temporary HTTP/HTTPS tunneling service built for Render Web Services and Android Termux. It establishes a persistent outbound WebSocket tunnel to expose local ports without port-forwarding or public IP addresses.

Step 1: Install Node.js in Termux

pkg update && pkg install nodejs

Step 2: Install or Clone R-Tunnel Client

curl -fsSL https://raw.githubusercontent.com/rajuan/r-tunnel/main/client/install.sh | bash

Step 3: Expose Local Port

rtunnel 8080

Security Architecture

• Strict SSRF Shielding: The Render tunnel server never proxies arbitrary outbound IPs. Client connections forward exclusively to 127.0.0.1.
• Server-authoritative expiration: Enforced strictly server-side (30m, 1h, 2h, 3h).
• Binary body integrity: Automatic Base64 transport preserves binary responses (images, media, PDFs).
